# 🐱 Michy y yo — Página Web de Clínica Felina

Proyecto de **HTML y CSS** para el curso de **Fundamentos de Programación (DAW/DAM/ASIR)**.

Landing page para una clínica felina ficticia, con diseño moderno, responsive y funcionalidades interactivas.

---

## 🛠️ Tecnologías

- **HTML5** (semántico)
- **CSS3** (variables, flexbox, grid, media queries)
- **JavaScript** (formulario interactivo)
- **Font Awesome** (iconos)

---

## ✨ Características

- ✅ Diseño responsive (móvil, tablet, escritorio)
- ✅ Header sticky con navegación
- ✅ Sección Hero con llamada a la acción
- ✅ Tarjetas de servicios con hover
- ✅ Sección "Sobre Nosotros" con imagen
- ✅ Testimonios de clientes
- ✅ Formulario de contacto funcional
- ✅ Footer con enlaces legales y redes sociales
- ✅ Paleta de colores coherente
- ✅ Animaciones y transiciones suaves

---
